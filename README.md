# CNN Architecture Study

An experimental study of CNN architectural behavior for image classification.

## Objective

The goal of this project is to understand how architectural design choices affect CNN classification behavior.

Rather than simply comparing pretrained models, each architecture is studied independently through controlled experiments.

## Architectures

1. VGG
2. Network in Network (NiN)
3. GoogLeNet / Inception
4. ResNet
5. DenseNet

## Experimental Approach

Each architecture has its own experimental design based on the architectural ideas that define it.

Training conditions will be controlled where appropriate so that architectural changes can be studied systematically.

## Dataset

Stanford Cars image classification dataset.

The dataset is stored separately in Google Drive and is excluded from this Git repository.
